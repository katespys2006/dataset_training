# Класифікація жанру книжки за уривком тексту

**Задача:** за уривком книжки (200 слів англійською) визначити її жанр: детектив, фантастика або романтика/класика.
**Що зроблено:** зібрано власний датасет із книжок Project Gutenberg, навчено три моделі різної складності
(логістична регресія, Random Forest, нейромережа) і порівняно їх за точністю та швидкістю.

## Структура проєкту

| Файл | Що робить |
|---|---|
| `dataset.csv` | Датасет: 1500 рядків (уривків по 200 слів). Колонки: `text`, `genre`, `book`, `author`, `split` |
| `build_dataset.py` | Як зібрано датасет (завантаження книжок з Project Gutenberg і нарізання на уривки). Потрібен інтернет, запускати не обов'язково |
| `1_prepare_data.py` | Ділить дані на навчальні й тестові (за книжками), перетворює текст у числа (TF-IDF), зберігає в `prepared/` |
| `2_model_logreg.py` | Модель 1: логістична регресія (проста) |
| `3_model_random_forest.py` | Модель 2: Random Forest (середня) |
| `4_model_neural_net.py` | Модель 3: нейромережа MLP (складна) |
| `5_results_and_plots.py` | Збирає результати трьох моделей у таблицю і будує графіки |
| `results.csv` | Підсумкова таблиця результатів |
| `plot_accuracy.png`, `plot_time.png` | Графіки точності та часу |
| `confusion_matrices.png` | Матриці помилок трьох моделей |
| `requirements.txt` | Список потрібних бібліотек |

Папки `prepared/` і `results/` створюються автоматично під час запуску.

## Датасет

- 3 класи (жанри) × 5 книжок × 100 уривків = **1500 рядків**, класи рівні (по 500).
- У кожному жанрі 2-3 різні автори, щоб модель вчила жанр, а не стиль одного автора.
- Колонка `split` ділить дані **за книжками**: по одній книжці кожного жанру йде в тест
  («The Moonstone», «From the Earth to the Moon», «Wuthering Heights»). Тобто 1200 рядків для навчання і 300 для тесту.
  Уривки однієї книжки ніколи не потрапляють одночасно і в навчання, і в тест, тому точність не завищена.

## Як запустити

**Важливо:** файли запускаються по черзі, від 1 до 5. Файли 2-4 потребують результату файлу 1.

## Очікуваний результат

- Крок 1 друкує `Навчання: 1200 рядків, тест: 300 рядків`, три тестові книжки, класи
  `['detective', 'romance', 'scifi']` і розмір матриці `(1200, 5000)`.
- Кроки 2-4 друкують по одному рядку з accuracy, F1 і часом (кілька секунд на модель).
- Крок 5 друкує звіт по кожному класу та підсумкову таблицю, створює `results.csv` і три картинки.

Приклад підсумкової таблиці (на твоєму комп'ютері цифри трохи відрізнятимуться, особливо час):

| Модель | Accuracy | F1 (macro) | Час навчання, с | Час передбачення, с |
|---|---|---|---|---|
| Logistic Regression (проста) | 0.6033 | 0.5947 | 0.461 | 0.0007 |
| Random Forest (середня) | 0.5567 | 0.5475 | 1.544 | 0.0763 |
| Neural Network MLP (складна) | 0.6733 | 0.6762 | 3.976 | 0.0092 |

Стабільні висновки при будь-якому запуску: логістична регресія найшвидша, нейромережа найточніша,
Random Forest не виграє ні за точністю, ні за швидкістю. Випадкове вгадування дало б 33%.

## Обмеження

- Тест містить лише по одній книжці на жанр, тому різниця в кілька відсотків між моделями може бути випадковою.
- Жанр за 200 словами визначити складно: детектив і романтика часто плутаються (див. `confusion_matrices.png`).
- Час виконання залежить від комп'ютера.
